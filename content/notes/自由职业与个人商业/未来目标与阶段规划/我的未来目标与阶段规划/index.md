我想买两辆房车，带着一家人环游中国，在路上生活、卖咖啡。我继续远程办公，也持续创作，朝着 B 站百大 UP 主的目标前进。

我的起点是裸辞，接下来要重新建立持续收入，同时推进内容创作、开源参与和英语学习，再逐步准备买车与出发。暂时不设完成日期，按实际进展推进。

## 一、我想实现的生活

| 方向 | 长期目标 |
| --- | --- |
| 家庭与生活 | 买两辆房车，带一家人环游中国，有更多时间一起生活 |
| 咖啡经营 | 和家人一起卖咖啡，让经营咖啡成为旅途中的日常 |
| 工作与收入 | 通过远程办公获得持续收入，让工作可以跟着自己走 |
| 内容创作 | 认真经营 B 站账号，持续做出自己满意的作品，争取成为百大 UP 主 |
| 技术成长 | 持续参与自己使用和认可的开源项目，积累公开贡献与协作经验 |
| 英语能力 | 比较轻松地读懂英文文章，并能用英语与外国人流利交流 |

## 二、先建立收入基础

### 当前起点：裸辞后重新建立收入

先整理现有可用资金、每月必要支出和已有收入，算清暂时没有新增收入时，资金能支持多久。这决定当前要投入多少时间挣钱，以及能留多少时间做内容。

### 收入阶梯：1000 → 2000 → 5000 → 10000 元

这里的月收入，按扣除业务成本后、个人生活支出前的实际到账收入计算。收入可以来自工作、接单或内容业务，不要求全部由 B 站提供；存款转入和借款不算收入。

| 阶段 | 月收入目标 | 这一阶段想做好的事 |
| --- | --- | --- |
| 第一阶段 | 1000 元 | 完成实际付费工作，先跑通从找到机会、交付到收款的过程 |
| 第二阶段 | 2000 元 | 继续获得订单或工作收入，找到能重复获得收入的方式，记录投入时间与成本 |
| 第三阶段 | 5000 元 | 提高交付效率与收入持续性，对照必要生活支出检查缺口，逐步落实可远程完成的工作 |
| 第四阶段 | 10000 元 | 争取持续达到这一水平，兼顾工作与创作，按实际结余积累购车与出发资金 |

这组金额作为我的个人推进台阶：先从较小的付费成果起步，再提高重复获得收入的能力，逐步走向月入 5000 元和 10000 元。它们不代表各阶段一定够生活，也不与粉丝数绑定。

单月达到目标，记录为一次达成，并继续向下一档推进；我将连续三个月达到同一档目标，作为该档收入持续性的初步检查标准。同时记录收入来源，确认下一阶段是否还有可继续承接的工作。

即使先达到较低一档，也要继续争取覆盖必要生活支出的收入机会；如果直接获得更高收入，就按实际进展推进，无需逐档等待。

### 从收入目标走向出发预算

月入 10000 元是当前设定的收入里程碑。是否足够支撑一家人的房车生活，要结合实际开支、可远程获得的收入和储蓄判断。

先了解费用，再确定需要攒下的金额，分别记录以下几项：

- 两辆房车的购买、整备与必要设备费用。
- 咖啡设备、原料及经营准备费用。
- 一家人在旅途中的日常生活、车辆使用和维护费用。
- 应对收入中断与临时支出的备用金。

具体金额在了解车型、家庭需求和出行方式后补充，逐步形成可以执行的储蓄目标。

## 三、逐步推进 B 站创作目标

创作与收入同步推进，分别记录进展。粉丝目标不直接对应收入金额。

| 阶段 | 目标 | 这一阶段想做好的事 |
| --- | --- | --- |
| 第一阶段 | B 站 1 万粉 | 持续发布作品，探索自己愿意长期做的内容，积累第一批认可我的观众 |
| 第二阶段 | B 站 10 万粉 | 逐步明确内容方向，打磨选题、表达和制作，持续积累认可我的观众 |
| 第三阶段 | B 站 100 万粉 | 在已有内容基础上，尝试更完整的系列和项目，让更多人认识我 |
| 长期目标 | B 站百大 UP 主 | 持续做出自己满意、也值得观众期待的作品，争取获得认可 |

百大 UP 主是长期争取的目标，单独记录，不以达到某个粉丝数作为完成标准。

## 四、逐步参与开源项目

我希望在实际项目中学习技术、解决问题，也与其他开发者协作。先从自己正在使用、与已有技能相关的项目开始，逐步完成贡献。

| 阶段 | 目标 | 这一阶段想做好的事 |
| --- | --- | --- |
| 第一阶段 | 选定一个项目并运行起来 | 阅读项目说明和贡献指南，熟悉使用方式，找到一个自己能复现或改进的问题 |
| 第二阶段 | 提交首次贡献 | 从具体问题入手，提交问题复现、文档改进或代码修复，并按项目要求说明和验证改动 |
| 第三阶段 | 完成贡献反馈与修改 | 跟进维护者反馈，补充说明或调整改动，争取让贡献被接受 |
| 长期目标 | 持续参与项目 | 围绕实际需求继续贡献，逐步承担更完整的问题，保留可公开查看的成果记录 |

贡献记录写清自己解决了什么问题、提交了什么，以及最终处理结果。相关实践可以整理成博客或视频素材。

裸辞初期优先落实收入，开源参与结合现有技能和可投入时间推进，不以贡献数量作为硬性任务。

## 五、逐步提高英语阅读与交流能力

我的英语目标是能实际使用：阅读时能理解文章的意思和论述，交流时能听懂对方、表达想法，并继续聊下去。

阅读和听说同步练习，结合自己感兴趣的文章、正在使用的开源项目，以及生活和工作中的交流场景推进。

| 阶段 | 阅读目标 | 交流目标 |
| --- | --- | --- |
| 第一阶段 | 借助词典读懂简短文章或项目说明，能用自己的话概括主要内容 | 能做自我介绍，围绕生活和工作进行简单问答，听不懂时能请求重复或解释 |
| 第二阶段 | 独立读完熟悉领域的文章，理解主要观点和关键细节，只查影响理解的词句 | 能围绕熟悉话题持续交流，描述经历、表达意见，并回应对方的追问 |
| 长期目标 | 比较轻松地阅读感兴趣的英文文章和技术资料，理解作者的观点与依据 | 能与外国人较流利地交流日常和工作话题，解释问题、讨论方案，遇到表达障碍时能换一种说法继续沟通 |

当前从适合自己水平的短文和简短对话开始。读完后做简要复述，听说练习围绕真实想表达的内容展开，再逐步增加文章长度和交流难度。

每月记录自己能独立读懂什么、能聊清楚什么，以及哪些地方仍依赖翻译或提示，以实际使用情况检查进步。

## 六、从准备走向房车生活

收入与创作推进的同时，逐步验证一家人是否适合这样的生活。买车和出发的时间，结合资金、工作与家人的意愿决定。

| 步骤 | 要完成的事 |
| --- | --- |
| 家庭沟通 | 讨论谁愿意参与、各自期待怎样的生活，以及工作、驾驶和咖啡经营如何分工 |
| 小规模体验 | 先尝试短途房车生活和咖啡制作，了解实际感受与花费；尝试经营前确认当地要求 |
| 远程工作试行 | 在短途出行中实际完成工作，检查网络、工作空间和时间安排是否合适 |
| 购车准备 | 根据体验确定两辆房车的需求，完善预算，积累购车与出发资金 |
| 正式出发 | 家人达成共识、资金准备到位、工作安排可行后，再确定出发计划 |

这部分按生活准备情况推进，不设置粉丝数门槛。

## 七、当前先做什么

当前先争取月入 1000 元，跑通付费工作与收款，再向 2000 元推进。B 站以 1 万粉为第一阶段目标，开源先选定一个项目并熟悉使用，英语从短文阅读和简单交流开始，房车与咖啡以了解需求、积累经验为主。

| 方向 | 当前行动 |
| --- | --- |
| 收入 | 整理可用资金与必要支出，落实付费工作，完成交付和收款，记录实际收入、业务成本和结余 |
| 创作 | 持续完成并发布作品，结合观众反馈打磨内容，向 1 万粉推进 |
| 开源 | 选择一个自己使用且与已有技能相关的项目，运行起来，阅读贡献指南，寻找可处理的问题 |
| 英语 | 选择能理解大意的英文短文，读后简要复述；练习自我介绍和生活、工作中的简单对话 |
| 家庭 | 和家人讨论房车生活及卖咖啡的想法，了解参与意愿 |
| 生活准备 | 了解房车与咖啡的实际费用，逐步补充预算 |

每月回顾收入、结余、作品、粉丝、开源贡献和英语使用情况，确定下一阶段最需要推进的事情。具体的每周与每日执行安排，放在[每周与每日时间安排]({{< relref "notes/自由职业与个人商业/未来目标与阶段规划/每周与每日时间安排/index.md" >}})中。
