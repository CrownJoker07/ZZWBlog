当前处于三人自媒体工作室的起步阶段，三人分别负责各自账号的日常运营。作为工作室负责人，同时运营个人账号，统筹三个账号的方向、阶段目标、进度、资源与商业合作。

采用每天推进工作、穿插娱乐与生活事务的方式，暂不设固定的整天休息日。个人可按状态调整工作量和休息时间。

## 每周安排

每人提出自己账号的每周成果与发布时间，由负责人协调目标和资源，各自推进具体内容。先试行以下安排：

| 节奏 | 主要安排 |
| --- | --- |
| 每天 | 各自明确当天重点，简短同步进度与阻碍；负责人跟进需要协调的事项 |
| 任务推进中 | 各自明确内容的完成标准与发布时间；相互协助时约定具体事项和时间 |
| 每周阅读与写作 | 至少读完一本书，整理核心观点、分析与个人思考，完成一篇文章 |
| 每周一次眼界与思维拓展 | 从外部交流、实地观察、案例分析、观点比较或小实验中选择一种，记录发现、依据与个人思考，在复盘时轮流分享 |
| 每周一次，约 30—60 分钟 | 负责人组织复盘，讨论三个账号的进展、问题与经验，确定下周各账号重点及需要协调的资源 |

每周复盘各自检查已发布内容、受众反馈、商业合作与收入进展，以及制作耗时和遇到的问题。负责人汇总工作室整体进展，协调优先级与资源；每人明确下一周继续什么、调整什么、暂缓什么，形成个人任务清单。

阅读与写作穿插在每日自主安排的时间中。文章写清书中的主要观点、论据、适用范围，以及自己的分析和可尝试的行动；引用或转述时注明出处，区分作者观点与个人判断。每周复盘检查阅读进度与文章完成情况。

## 每日安排

起床后用半小时规划今日，分别明确个人账号的重点成果和工作室需要统筹的事项，提前约定沟通时间，保留个人创作时段。睡前准备与睡眠保持固定时间，其余时间自主安排工作、三餐、家务、午睡、运动与休闲。

| 安排 | 时长或固定时间 |
| --- | --- |
| 起床后规划今日 | 半小时 |
| 工作与生活自主安排 | 16 小时 |
| 睡前洗漱、准备休息 | 23：00—23：30，半小时 |
| 睡眠 | 23：30—次日06：30，7 小时 |

娱乐与休息穿插安排；如需相互协助拍摄或讨论，提前约定时间。

## 执行与调整

- 每天开始：明确一项最重要的成果，例如完成可演示功能、提交交付版本或发布一篇内容。
- 计划变化：使用缓冲时间，必要时推迟次要任务；涉及对外交付时及时沟通。
- 每天下班：记录进展和下一步，结束工作。
- 每周调整：结合各账号进展、工作室目标与个人生活状态，协调任务量和资源，调整各自的时间安排。
