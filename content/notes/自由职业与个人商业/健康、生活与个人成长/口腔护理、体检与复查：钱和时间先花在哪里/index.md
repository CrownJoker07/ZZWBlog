健康管理先处理三件事：**日常护理、已经出现的症状、医生要求的复查**。体检套餐项目多，不能保证更适合自己。

## 口腔护理每天做什么

| 事项 | 做法 |
| --- | --- |
| 刷牙 | 每天两次，每次约两分钟，使用含氟牙膏；其中一次在睡前 |
| 清洁牙缝 | 每天用牙线或合适的牙间刷清洁 |
| 刷完以后 | 吐出多余牙膏，避免立即用水大量漱口 |
| 牙科检查 | 根据牙齿、牙龈状况，由牙医确定复查间隔 |

以上参考 [NHS 口腔清洁指南](https://www.nhs.uk/live-well/healthy-teeth-and-gums/how-to-keep-your-teeth-clean/)。手动牙刷也能做好清洁，先掌握方法，再考虑更贵的工具。

**牙痛、牙龈反复出血或肿胀要安排牙科就诊**，不能只靠换牙膏、漱口水或等年度体检。症状与处理见 [NHS 牙龈疾病说明](https://www.nhs.uk/conditions/gum-disease/)。

## 26 岁选体检，先带哪些信息

预约前准备既往体检报告、用药、家族病史和当前不适。请医生按年龄、个人风险与已有问题选择检查项目，并问清哪些检查有必要、何时复查。

北京清华长庚医院的[体检项目说明](https://wjw.beijing.gov.cn/bmfw_20143/jkzs/jksh/202408/t20240820_3777463.html)强调依据既往史、家族史、年龄及风险选择项目，并遵医嘱跟进异常结果。不能仅因年轻就忽略血压、体重等基础情况，也不应直接照搬中老年或高风险人群的筛查清单。

**已经持续不舒服，应挂相应门诊**，向医生描述症状；购买体检套餐不能代替针对性诊疗。

## 报告留下什么

用一个文件夹保存报告，另列一张待办表，避免反复检查却没有处理结果。

| 项目 | 需要留下的信息 |
| --- | --- |
| 已发现的问题 | 检查日期、结果、医生判断 |
| 下一步 | 是否治疗、生活调整或复查 |
| 复查 | 时间、科室、要带的旧资料 |
| 用药 | 药名、用法、开药医生；调整按医嘱 |

预算紧时，先向医生说明费用限制，明确必要检查与可分步完成的事项。医保报销按就诊项目和参保规则办理，不能预设体检、洁牙等所有费用都能报销；参保安排见[五险一金文章]({{< relref "notes/自由职业与个人商业/生活保障与风险管理/社保医保的缴纳与衔接/index.md" >}})。
