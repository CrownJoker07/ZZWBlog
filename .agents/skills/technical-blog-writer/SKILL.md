# 技术博客写作

## 工作流程

1. 明确文章主题、目标读者和读者收获。
2. 按逻辑顺序组织内容，由浅入深解释技术概念。
3. 提供清晰、准确且可运行的代码示例。
4. 使用适当的标题、图表、代码块和列表增强可读性。
5. 校对全文，修正逻辑、术语、语法和排版问题。

## 写作要求

- 使用简洁明确的语言，避免冗长句式。
- 准确解释技术概念，统一使用规范术语。
- 任何定义都必须附上权威来源的网站链接，优先引用官方文档、标准组织或原始规范页面，便于读者核验。
- 开头简要说明主题和读者收获。
- 主体按逻辑顺序展开，由浅入深。
- 结尾归纳要点，必要时提供延伸学习资源。
- 对关键技术点使用加粗或代码高亮。
- 使用层次清晰的段落和适当的标题级别。

## 代码示例

- 优先采用主流编程语言的现代写法。
- 确保示例完整并可运行。
- 为关键逻辑添加必要的中文注释。
- 分步解释复杂代码。
- 为较长代码添加行号。

## 最终检查

- 确认主题明确且标题具有吸引力。
- 确认内容完整、结构合理且逻辑连贯。
- 验证代码示例可以正确运行。
- 检查术语是否准确并保持一致。
- 修正错别字、语法错误和排版问题。
